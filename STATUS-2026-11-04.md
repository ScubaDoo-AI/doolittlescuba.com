## Tooling

The whole operation runs from the GitHub repository `ScubaDoo-AI/doolittlescuba.com` (Porkbun publishes `main` in about a minute) and four GitHub Actions that can be started from the iPad. Keys live only in GitHub secrets: `PRINTFUL_TOKEN`, and the "Doolittle Order Bot" app's `SHOPIFY_CLIENT_ID` / `SHOPIFY_CLIENT_SECRET` (read orders, read and write files).

| Action | What it does |
| --- | --- |
| Check connections | Read-only: Shopify token and scopes, Files access, Printful store and synced products |
| Printful link | Links one or more lines through the sync API; dry run unless "apply"; "force" re-sends |
| Personalized order | Dry run, draft or confirm a name-shirt order from a Shopify order number |
| Sample order | Drafts one Printful order of chosen SKUs to the sample address |

Each line has its own trio of scripts in `tools/`: a design list (JSON), a renderer for mockups and previews, and a Shopify input builder, plus a Printful plan (`printful_<line>.py`). The 1N73LL1G3NC3 line renders straight from its Design canvas (`n73_art.py`), so an edit on an artboard is one run away from the site, the store and the print file. `SHOPIFY-STORE.md` and the dated changelogs in the repository (copied to the Project) are the record of every id, price and decision.

## What blocks launch

Nothing technical is in the way; these are the settings and decisions only the owner can make, in the order they matter.

- [ ] **Shopify Payments** — business details, EIN, payout account
- [ ] **Printful billing and the Georgia tax certificate** — without them Printful will not fulfil
- [ ] **Revoke and re-issue the Printful token** used in chat on 3 Nov, and update the GitHub secret
- [ ] **Samples** — run the Sample order job (one Signature dark, one personalized, one Certified-ish) and approve the prints before anything goes live
- [ ] **Shipping** — replace the default US rates (the $0 Standard rate in particular); decide on a Rest of World zone
- [ ] **Taxes** — register with the GA Department of Revenue, then add Georgia under Taxes and duties
- [ ] **Policies** — refund, shipping and terms of service, with the made-to-order note
- [ ] **Domain** — connect shop.doolittlescuba.com and add the CNAME at Porkbun
- [ ] **Theme** — test an add-to-cart on a personalized tee in the unpublished theme, then publish it
- [ ] **Go live** — products Active, `coming-soon` tags off, collections published, the site's pills become Buy buttons, Shop in the nav

Until then everything stays Draft; the one exception is the 32 stickers, Active on no channel so Printful could import them.

## Open design items

- **Off-World Hunt Club** — the package README asks for the glyphs to be redrawn by hand before the copyright filing; the garment pairings (one light, one dark per design) are easy to swap in `tools/offworld_designs.json`
