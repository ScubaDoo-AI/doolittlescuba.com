# doolittlescuba.com

Source of the Doolittle Scuba L.L.C. website, published by Porkbun static hosting straight from the `main` branch (GitHub Connect). Plain HTML/CSS/JS, no build step: `index.html` at the root is the home page; `/about/`, `/workshop/` and `/sites/<slug>/` are the other pages; images live under `img/`, `about/img/` and `workshop/img/`.

Change log: `CHANGELOG-2026-10-18.md`, `CHANGELOG-2026-10-20.md`, then the commit history.
